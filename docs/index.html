Sound familiar? Between your terminals, your editor and the AI agents that spin up dev servers and forget about them, ports pile up. PortBar shows you all of them — and who to blame.

Features

Everything you need.
Nothing you don't.

🕵️

Knows who started it

PortBar walks each process's parent chain — and when the launching shell is long gone, reads the environment the server inherited — to tell you whether it came from you, your editor, or an AI coding agent running in the background.

Claude Code Codex Gemini CLI Aider VS Code Cursor Zed Terminal iTerm2 Warp Ghostty Docker launchd
⏹️

Stop in two clicks

Click stop, click again to confirm. If a process ignores the polite request, PortBar offers a Force Kill.

■→ Stop→ Force Kill
📁

See the project

Every port shows the folder it was started from. Jump to it in Finder or open it in your browser.

~/Code/shop-web
📡

Spot exposed ports

Servers listening on all interfaces get a network tag — anyone on your Wi-Fi can reach them.

🔢

Live count in your menu bar

Glance up to see how many ports are open. The list refreshes every few seconds while it's open.

🪶

Tiny & native

Pure Swift and SwiftUI. No Electron, no runtime, no background daemon.

~1 MBdownload
0dependencies
🔍

Search & filter

Type a port, process or folder. Filter by Agents, Terminal, Editors or Services. System noise is hidden by default.

🫧

Liquid Glass

A frosted glass panel that drops from the menu bar — native Liquid Glass on macOS 26, light and dark.

How it works

Three steps.
That's it.

1

Install

Download, unzip, drag PortBar to Applications and open it. It sits quietly in your menu bar — no Dock icon.

2

Click the icon

See every open port with its process, project folder, uptime, memory and who launched it.

3

Stop what you don't need

Free up port 3000 in two clicks — or clear out every forgotten dev server at once.

Privacy

Zero permissions.
Zero network.

PortBar reads the same information as lsof and ps — nothing more.

🔓

No special access

No Accessibility, no Screen Recording, no admin password. It can only stop processes that belong to you.

🛡️

Nothing leaves your Mac

No network calls, no telemetry, no analytics, no account. Open source — read every line on GitHub.

⚠️ macOS will block the app on first launch — here's how to open it

Because PortBar isn't from the App Store, macOS shows a security dialog. You'll see "PortBar.app Not Opened" with Done and Move to Bin buttons. Do not click Move to Bin. Follow these steps instead:

1
Click Done to dismiss the dialog.
2
Open System Settings → Privacy & Security.
3
Scroll down to the Security section. You'll see:
"PortBar was blocked from use because it is not from an identified developer."
Click Open Anyway.
4
Enter your password or use Touch ID to confirm. PortBar will launch. You only need to do this once.
1
Unzip the downloaded file and move PortBar.app to your /Applications folder.
2
Launch PortBar. If macOS blocks it, go to System Settings → Privacy & Security and click Open Anyway. See step-by-step guide ↑
3
Click the terminal icon in your menu bar — that's it. No permissions to grant.
4
Optional: turn on Launch at login from the ⋯ menu so it's always there.
